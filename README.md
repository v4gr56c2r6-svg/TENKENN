# TENKEN PRO 店舗版（初期プロトタイプ）

## できること
- 清掃・設備の初期チェック項目
- OK / NG / 対象外の記録
- 担当者名の端末内保存
- 点検日ごとの履歴
- 点検項目の追加
- JSONバックアップの書き出し・復元
- PWA / オフライン起動の基礎対応

## 重要な制限
この初期版は `localStorage` にデータを保存します。データはブラウザ・端末ごとに独立しており、スタッフ間で自動共有されません。ブラウザデータの消去や端末故障で失われる可能性があるため、バックアップを定期的に書き出してください。
複数人で共有する運用に移る前に、認証・権限・クラウドDB・写真保存・バックアップ方針を設計します。

## 起動・公開
1. ZIPを展開します。
2. `index.html` を確認できます（PWAインストール・オフライン機能はHTTPS配信が必要）。
3. GitHub PagesなどHTTPS対応の静的ホスティングへフォルダ内のファイルを配置します。
4. iPhoneのSafariで公開URLを開き、「共有」→「ホーム画面に追加」を選びます。

## 初期項目について
清掃・設備項目はサンプルです。実際の店舗ルール、衛生管理基準、設備メーカーの点検要領、会社の安全手順に合わせて必ず見直してください。このアプリのチェック結果は法定点検や専門資格者による点検の代替にはなりません。


## v2 追加機能：写真付き異常報告
- 異常タイトル、分類、緊急度、状況メモを登録
- iPhoneのカメラまたは写真ライブラリから画像を選択
- 画像を長辺1280px・JPEGに縮小してIndexedDBへ保存
- 報告履歴の表示と「対応済み／未対応」の切り替え

### 注意
写真データはIndexedDB、報告本文はlocalStorageに端末内保存します。ブラウザのサイトデータ消去、端末故障、ストレージ整理などで失われる可能性があります。写真データは現行JSONバックアップには含まれません。クラウド共有・写真バックアップ機能は今後の開発対象です。


## v2: 写真付き異常報告
- 異常のタイトル、分類、緊急度、状況説明を保存
- iPhoneのカメラ／写真ライブラリから写真を1枚添付
- 写真を長辺1000px・JPEGに圧縮して端末内に保存
- 未対応／対応済みの切り替え、報告削除
- JSONバックアップに異常報告・写真も含める

写真データもブラウザの保存領域を使います。容量には上限があり、端末やブラウザのデータ消去で失われる可能性があります。大切な記録はバックアップしてください。初期版はスタッフ間共有されません。
