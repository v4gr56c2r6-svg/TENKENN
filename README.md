# TENKEN PRO 店舗版（初期プロトタイプ）

## できること
- 清掃・設備の初期チェック項目
- OK / NG / 対象外の記録
- 担当者名の端末内保存
- 点検日ごとの履歴
- 点検項目の追加
- JSONバックアップの書き出し・復元
- PWA / オフライン起動の基礎対応

## 重要な制限
この初期版は `localStorage` にデータを保存します。データはブラウザ・端末ごとに独立しており、スタッフ間で自動共有されません。ブラウザデータの消去や端末故障で失われる可能性があるため、バックアップを定期的に書き出してください。
複数人で共有する運用に移る前に、認証・権限・クラウドDB・写真保存・バックアップ方針を設計します。

## 起動・公開
1. ZIPを展開します。
2. `index.html` を確認できます（PWAインストール・オフライン機能はHTTPS配信が必要）。
3. GitHub PagesなどHTTPS対応の静的ホスティングへフォルダ内のファイルを配置します。
4. iPhoneのSafariで公開URLを開き、「共有」→「ホーム画面に追加」を選びます。

## 初期項目について
清掃・設備項目はサンプルです。実際の店舗ルール、衛生管理基準、設備メーカーの点検要領、会社の安全手順に合わせて必ず見直してください。このアプリのチェック結果は法定点検や専門資格者による点検の代替にはなりません。
